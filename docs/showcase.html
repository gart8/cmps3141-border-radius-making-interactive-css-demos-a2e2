What it helps you see

One property, three ways to understand it.

The interface keeps the code visible while the preview makes each change concrete.

Clockwise mapping

Numbered corner markers show how one, two, three, and four-value shorthand expands around the box.

Ellipse anatomy

Paired horizontal and vertical inputs reveal that an elliptical corner is controlled by two radii, not one.

Direct manipulation

Drag the orange border to experiment directly, or use precise numeric controls when you need exact CSS.

Designed for learning

A short path from curiosity to confidence.
