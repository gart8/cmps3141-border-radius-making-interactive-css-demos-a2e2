Each corner has a horizontal radius and a vertical radius.

TL (value 1)
TR (value 2)
BR (value 3)
BL (value 4)

All four corners use Value 1.

1st/3rd corners use Value 1. 2nd/4th use Value 2.

Top-left: 1, top-right/bottom-left: 2, bottom-right: 3.

Values travel clockwise: top-left, top-right, bottom-right, bottom-left.

Before / after the slash: horizontal radii / vertical radii. Each side follows the same clockwise order.
